# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately** via GitHub: on the affected repository open the **Security** tab and choose **Report a vulnerability** (private vulnerability reporting). Do not open a public issue, discussion or pull request.

Include the affected version, a description of the impact, and steps to reproduce or a proof of concept if you have one.

## What happens next

- Your report is triaged promptly. Fixes are developed in private and released as patch versions.
- Publishing a security advisory or requesting a CVE is decided by the owner.
- We credit reporters in the advisory unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
