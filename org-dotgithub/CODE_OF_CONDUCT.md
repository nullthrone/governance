# Code of conduct

These projects follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions on topic, and do not harass anyone. Maintainers may remove content and block participants who violate this code.

Report incidents privately to the owner, [@t11z](https://github.com/t11z), using the contact information on the GitHub profile. Reports are handled confidentially.
